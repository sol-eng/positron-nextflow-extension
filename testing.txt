  To test on Workbench:
  1. Install dev.9, and keep the launcher from the headless branch (needed for the graceful
     stop).
  2. Run examples/rnaseq and choose As a Workbench Job. Within a few seconds you should see
     nf-driver-… and then the nf-* task jobs in the Jobs UI.
  3. Stop the session, wait a bit, and start a new one. Pipeline Runs should show the run still
     running, or finished, with the reports and dashboards working.
  4. Try Stop on a second headless run: the driver and its task jobs should end. Then try Force 
     Kill on a third: leftover task jobs should be cancelled within a few seconds.

  Two limits to know:
  - Credential lifetime: the job's credentials last 7 days, so a headless run can't run longer
    than that.
  - Image requirements: the driver image needs bash, ps and Java 17 or later. Nextflow, the
    plugin and the launcher come from your home directory, so the session image is fine.

  On posit-sdk-nextflow, PR #3 now also documents that driver jobs started from a session need no
  credentials. Once your Workbench test passes, I'd merge it and release the launcher as 0.3.0.
